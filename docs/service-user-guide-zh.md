# NearLink 安装式服务预发布使用说明

1. Mac 与 Windows 同步安装本次预发布，保留原身份及配对。
2. Windows 首次从 NearLink 托盘菜单选择“安装无人值守服务…”。在本机完成 UAC，核对允许无人值守的设备指纹，并确认可查看／操作普通桌面、管理员应用和安全桌面的范围。首次安装不能依赖尚未安装的 NearLink 服务批准自身。
3. 安装完成后，按提示完全退出原实例。服务会在当前已登录用户的会话中自动启动受保护的 NearLink。Mac 再次连接；已经批准的设备重连应无需本机再次确认。
4. 分别测试普通编辑器、管理员编辑器和 WeGame 的文字、点击、滚轮及拖动松手；再测试 UAC 提示能否显示、选择取消与允许后能否恢复，以及锁屏后连接与解锁。请把实际操作响应、视频刷新、指针位置分别观察。
5. 增加批准设备或更新服务组件需在 Windows 托盘重新运行安装；仅软件重连不应触发安装确认。停止后台程序可在 Windows 服务管理器停止／禁用 NearLinkDesktopService。退出界面后服务会再次启动客户端，这是无人值守运行方式。

本轮不包含重启后尚未登录的远程入口，受系统保护内容及所有特殊按键也不能从普通输入成功推定支持。性能、系统音频、多屏及长期稳定性以实际测试为准。不要上传设备身份、配对资料、原始日志或个人截图；反馈版本、问题步骤和脱敏结果即可。
