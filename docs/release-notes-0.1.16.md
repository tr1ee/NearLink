# NearLink 0.1.16 预发布

修复 0.1.15 Windows 安装式桌面服务的设备指纹校验、连接后黑屏和有画面但键鼠无响应。设备指纹统一为项目既有的公钥 SPKI 摘要；服务采集 worker 正确读取服务帧；可靠通道通知桌面代次；输入线程使用完整的桌面访问权限进行系统注入。

Windows 本地修正构建已与已安装的 Mac 0.1.15 完成普通桌面、管理员编辑器、UAC 显示／取消后返回、免本机批准重连和锁屏解锁测试。发布产物仍需通过软件内更新后回归，测试通过不能替代长期稳定性验证。

首次安装仍需本机管理员批准并核对允许的控制端指纹。组件安装／更新需要 UAC；同范围安装批准保留，正常断开重连不启动安装器。本轮支持已经登录后的会话，未覆盖重启后尚未登录。系统音频、多显示器及受保护内容不计为已验收。

请从本版签名更新清单进行软件内更新。保持预发布，稳定 Latest 暂不改变。0.1.15 的旧产物不覆盖、不混用；符合双端验收预期后再转正。
