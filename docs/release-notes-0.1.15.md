# NearLink 0.1.15 预发布

本版用于 Mac → Windows 安装式服务联调。Mac 新增当前远控会话的设备签名证明；Windows 新增无人值守服务、受保护客户端和交互会话的桌面采集／输入工作进程。首次批准设备后，断线重连不再设计为重复本机 UAC 和会话批准。

Windows 首次在托盘选择“安装无人值守服务…”，在本机核对允许的设备指纹和普通／安全桌面权限。设备身份与配对保留在原用户目录。本轮范围为已经登录后的重连、管理员应用、UAC 与锁屏；尚未覆盖电脑刚重启、没有用户登录时的远程连接。

已完成编译、设备签名互验、输入进程回归和独立 Windows runner 的实际安装检查。服务已在 Windows 真机启动；UAC 画面／操作、锁屏、重连及稳定性需要通过本预发布完成双端验收，不能把安装通过当成所有功能已验收。测试期间不要启用 Computer Use 鼠标，避免干扰系统指针。

两端通过“设置 → 软件更新 → 更新源设置”使用本版本的 `nearlink-update.json` 清单，再检查、下载、安装。预发布保持 prerelease，稳定 Latest 不变；符合双端验收预期后再转正。
