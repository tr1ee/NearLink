# 近控 NearLink

Windows 11 与 macOS 14.2+ 的局域网远程桌面测试版。本仓库提供安装包、更新清单和使用说明。

[下载 0.1.10 测试版](https://github.com/tr1ee/NearLink/releases/tag/v0.1.10)

## 0.1.10 更新

- 修复 Mac 上重新激活应用、恢复远控窗口和切换全屏时的输入焦点问题。点击桌面后可继续向远端打字。
- 普通鼠标移动在原始事件未到达时可以继续转发。控制端保留本机光标。远端画面包含光标时，移动中可能短暂看到两个。
- 仅观看会话在工具栏标注。从首页发起远控会重新协商为可操作会话。
- 保留按远端显示器比例自动调整窗口的行为。性能诊断新增接收到提交、提交到预计显示两个时间区间。

## 安装和升级

在设置的「软件更新」中检查、下载并安装。应用重新打开后，原配对和设置仍可使用。Mac 控制 Windows 时，先更新 Mac 即可验证。装有 0.1.8 或 0.1.9 的 Windows 可以继续连接。

手动安装时，Windows 使用 `win-x64.exe`，Apple Silicon Mac 使用 `mac-arm64.dmg`，Intel Mac 使用 `mac-x64.dmg`。软件内更新会验证签名、安装包长度和 SHA-256。

## 使用

两台电脑需开机并登录，处于互通的同一局域网。首次配对需双方核对完整指纹。Mac被控时授予屏幕录制、辅助功能及相应音频权限；发现失败时可填写对端设置页的IPv4:端口。

点击预览进入独立全屏窗口，顶部悬浮工具栏提供显示器、文件、画质、声音和诊断。退出全屏后可移动、缩放。最小化或×隐藏到后台，通过托盘/菜单栏恢复；“断开”结束会话，“完全退出”结束程序。

文件使用独立双栏窗口，支持文件夹选择、常用位置、多选、递归传输和完整性校验。文字/图片剪贴板及被控端系统声音默认启用，不采集麦克风。

Mac控制Windows时，Command+R对应Win+R，Option+Tab对应Alt+Tab，Control+C/V对应Ctrl+C/V；Command+V保留为Win+V。Windows控制Mac时，Windows键对应Command，Alt对应Option，Ctrl保持Control。

按源屏原生分辨率采集，最高3840×2160，低分辨率源不放大。画质菜单分别设置分辨率与目标帧率，支持自动流畅、原生清晰和原始像素显示。120fps尚未开放。

## 验证

58 项单元与回环网络测试及 Electron 回归通过，覆盖真实 WebRTC 中的鼠标移动、点击、文字到达、窗口焦点与媒体恢复、独立输入和隔离更新。 [Windows 安装验证](https://github.com/tr1ee/NearLink/actions/runs/44867594335)

操作响应以真机点击到画面变化的时间为准。本版对照的 Chromium 呈现开关没有带来稳定的合成测试收益，诊断中新增的时间用于定位下一段优化。

Mac 使用本地测试签名，Windows 安装包未配置发布者签名。
