# 近控 NearLink

Windows 11 与 macOS 14.2+ 的局域网远程桌面测试版。本仓库用于发布安装包、更新清单及使用说明；源码暂未公开。

[下载最新测试版](https://github.com/tr1ee/NearLink/releases/latest)

## 功能

- 独立全屏远控窗口，退出全屏后可拖动、调整大小；关闭窗口后保持后台连接。
- 原生键鼠、文字与图片剪贴板、被控电脑系统声音。
- 双栏文件与文件夹互传，文件夹选择器、常用位置、多选和完整性校验。
- 按被控屏幕原生分辨率采集，最高4K；支持自动调整、原生清晰与原始像素显示。
- 双端指纹配对、固定公钥身份及加密传输。
- 应用内检查、下载更新，确认后安装并重新打开；清单和安装包均经过校验。

## 安装与升级

Windows 选择 `win-x64.exe`；M 系列 Mac 选择 `mac-arm64.dmg`；Intel Mac 选择 `mac-x64.dmg`。Mac 安装时将 NearLink 拖入“应用程序”，再从该位置启动。安装前请通过托盘／菜单栏“完全退出”旧版。

0.1.0 没有更新模块，因此首次升级到0.1.1仍需两台电脑各安装一次。此后可在“设置 → 软件更新”检查并下载安装。后台检查不会自动中断当前连接；安装前会确认结束会话和未完成的文件任务。

两台电脑需处于互通的局域网。Mac 被控时需授予屏幕录制、辅助功能及相应音频录制权限。首次配对时请核对两端设备指纹。

## 测试边界

当前为测试版本：Mac 使用 ad-hoc 签名，尚未 Apple 公证；Windows 尚未配置发布者签名。系统可能要求确认来源、权限或钥匙串访问。

4K 是采集上限，较低分辨率源不会放大。4K60、120fps、端到端延迟目标及8小时稳定性尚未认证，120fps暂不开放。Windows／Intel Mac真机和Windows自动安装仍需继续验证。声音、剪贴板及多屏功能也需要对应物理设备验收。

尚不提供手机端、跨互联网连接、登录前控制或系统服务。
