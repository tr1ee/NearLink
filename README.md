# 近控 NearLink

Windows 11 与 macOS 14.2+ 的局域网远程桌面测试版。本仓库提供安装包、更新清单和使用说明。

[下载 0.1.9 测试版](https://github.com/tr1ee/NearLink/releases/tag/v0.1.9)

## 0.1.9 更新

- 退出全屏或切换远端显示器时，窗口内容区按被控屏幕等比调整，超出本机可用区域时等比缩小。
- 支持原始指针事件的环境更早发送鼠标移动。远控工具栏和面板使用实体背景，减少视频播放期间的背景合成开销。
- 性能诊断增加平均采集帧间隔，帮助区分采集帧率和接收端等待。

## 安装和升级

在设置的「软件更新」中检查、下载并安装 0.1.9。安装会结束当前会话，完成后重新打开应用，保留原有配对和设置。Mac 控制 Windows 时可以先升级 Mac，Windows 0.1.8 仍可连接。

手动安装时，Windows 使用 `win-x64.exe`，M 系列 Mac 使用 `mac-arm64.dmg`，Intel Mac 使用 `mac-x64.dmg`。更新清单使用原有发布密钥签名，安装包下载后校验长度和 SHA-256。

## 使用

两台电脑需开机并登录，处于互通的同一局域网。首次配对需双方核对完整指纹。Mac被控时授予屏幕录制、辅助功能及相应音频权限；发现失败时可填写对端设置页的IPv4:端口。

点击预览进入独立全屏窗口，顶部悬浮工具栏提供显示器、文件、画质、声音和诊断。退出全屏后可移动、缩放。最小化或×隐藏到后台，通过托盘/菜单栏恢复；“断开”结束会话，“完全退出”结束程序。

文件使用独立双栏窗口，支持文件夹选择、常用位置、多选、递归传输和完整性校验。文字/图片剪贴板及被控端系统声音默认启用，不采集麦克风。

Mac控制Windows时，Command+R对应Win+R，Option+Tab对应Alt+Tab，Control+C/V对应Ctrl+C/V；Command+V保留为Win+V。Windows控制Mac时，Windows键对应Command，Alt对应Option，Ctrl保持Control。

按源屏原生分辨率采集，最高3840×2160，低分辨率源不放大。画质菜单分别设置分辨率与目标帧率，支持自动流畅、原生清晰和原始像素显示。120fps尚未开放。

## 验证

构建、58 项单元与回环网络测试、窗口与媒体回归、Mac 更新校验和隔离安装回归通过。[Windows 隔离安装验证](https://github.com/tr1ee/NearLink/actions/runs/44857060410)通过了最终包覆盖、版本校验、重启确认和缓存清理。

在原画质下退出全屏可验证窗口尺寸。比较操作延迟时，使用同一台被控电脑、同一显示器和相同帧率。可在性能诊断里打开对端测试画面并运行「测量操作响应」。实体显示器上的反馈仍需同机实测。

Mac 使用本地测试签名，Windows 安装包未配置发布者签名。
