# 近控 NearLink

Windows 11 与 macOS 14.2+ 的局域网远程桌面测试版。本仓库用于发布安装包、更新清单及使用说明；源码暂未公开。

[下载最新测试版 0.1.5](https://github.com/tr1ee/NearLink/releases/tag/v0.1.5)

## 功能

- 独立全屏远控窗口，退出全屏后可拖动、调整大小；关闭窗口后保持后台连接。
- 原生键鼠、文字与图片剪贴板、被控电脑系统声音。
- 双栏文件与文件夹互传，文件夹选择器、常用位置、多选和完整性校验。
- 按被控屏幕原生分辨率采集，最高4K；支持自动调整、原生清晰与原始像素显示。
- 双端指纹配对、固定公钥身份及加密传输。
- 应用内检查、下载更新，确认后安装并重新打开；清单和安装包均经过校验。

## 0.1.5 更新安装修复

修复Mac更新清理app.asar时报ENOTEMPTY：更新使用真实磁盘接口和独立解包目录，失败可重试，并防止重复点击并行安装。新版成功启动后清理旧应用备份、旧解包、当前及旧版本更新缓存；更高版本下载、配置与日志保留。

Windows辅助进程在安装版本与新程序启动均确认后删除本次安装包，失败时保留用于重试。清理仅限应用updates目录，不删除用户手动下载到Downloads中的文件。

46项自动测试和2项隐藏Electron更新回归通过。Mac回归调用真实生产AppUpdater、实际辅助进程和签名微型后台应用，覆盖失败、重试、互斥、替换、启动与ASAR缓存清理；未改动正式安装。Windows脚本使用实际PowerShell和最终ASAR验证四种分支，安装命令仍模拟，NSIS/UAC实机尚待确认。

## 0.1.4 媒体改动（0.1.5保留）

媒体采集与控制页使用独立渲染进程，减少首页隐藏的影响；媒体进程崩溃或持续无响应时自动重载并重新协商。采集等待可立即取消，旧会话故障不会中断新会话。

调整采集帧率约束与编码内容提示，优先连续交互；诊断新增目标/采集配置fps，低码率以kbps显示。正常动态操作以至少30fps验收，默认目标60fps，实际Windows帧率仍需真机验证。

“我的设备”只显示已配对身份，附近未配对电脑从“全部设备”选择；清除过期发现和失败握手的“连接中”占位。已有配对、公钥校验保留，不按名称合并信任。诊断导出新增后台调度和媒体恢复日志。

## 安装与升级

Windows选择 `win-x64.exe`；M系列Mac选择 `mac-arm64.dmg`；Intel Mac选择 `mac-x64.dmg`。Mac将NearLink拖入“应用程序”，从该位置启动。

请将两端升级0.1.5。Windows0.1.1/0.1.2仍使用旧更新器：请完全退出后手动运行0.1.5安装包覆盖原位置一次，可直接跳过中间版本。0.1.3及以后可在设置中更新，无需卸载或重新配对。

Mac0.1.4及更早版本如果已报旧updates/unpacked的ENOTEMPTY，需要先清理该失败解包残留再重新检查/安装，或完全退出后手动覆盖0.1.5一次。升级后使用修复的新流程。0.1.0没有更新模块，需手动覆盖。

后台检查不会自动中断当前连接；确认安装会结束当前会话。Windows从0.1.3起增加辅助进程就绪握手、安装版本校验和启动确认，真实NSIS/UAC和自动重启仍需Windows实机验证。

两台电脑需处于互通局域网。Mac被控时需授予屏幕录制、辅助功能及相应音频权限。首次配对请核对两端指纹。×用于隐藏到后台；托盘/菜单栏可恢复，“完全退出”结束程序。

## 验证与边界

0.1.4的43项自动测试及5项隐藏Electron回归通过；0.1.5未改动媒体。生产Runtime/TLS/IPC/WebRTC在本机合成1080p60动态测试中稳定后呈现约50fps，模拟输入到解码反馈P50约50ms、P95约67ms。两端媒体渲染器分别实际强制终止后可自动恢复，编码预热时短暂低于30fps。

以上使用合成画面与模拟输入，Windows平台分支在Mac进程内模拟；不能替代Windows真实桌面采集、Wi-Fi跨机、系统窗口管理器或物理显示器验收。两端升级后需继续测试动态画面、拖动窗口以及最小化/关闭后的恢复。

4K是采集上限，较低分辨率源不会放大。真实30fps、4K60、端到端延迟目标及8小时稳定性尚未认证；120fps暂不开放。声音、剪贴板及多屏也需对应设备验收。

Mac为ad-hoc测试签名，尚未Apple公证；Windows尚未配置发布者签名。尚不提供手机端、跨互联网连接、登录前控制或系统服务。
