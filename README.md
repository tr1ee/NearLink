# 近控 NearLink

Windows 11 与 macOS 14.2+ 的局域网远程桌面测试版。本仓库发布安装包、更新清单和使用说明；应用源码暂未公开。

[下载 0.1.7 测试版](https://github.com/tr1ee/NearLink/releases/tag/v0.1.7)

## 0.1.7 更新

- 修复Windows更新辅助进程未就绪便退出、日志为空的启动路径：GUI启动器创建隐藏控制台，SHA-256直接使用系统.NET，安装前确认辅助进程就绪，安装后校验实际版本并等待新程序就绪。
- 新版成功启动后清理当前/旧版更新包及对应启动器缓存，保留未来下载、配置和诊断日志。用户自己下载的安装包不属于应用缓存。
- Mac Command对应Windows键，Option对应Alt，Control对应Ctrl，不再将Command自动换成Ctrl。修正组合键抬起、粘贴后仍按住的修饰键及失焦后的延迟粘贴。
- 远控期间不再重复截取首页预览。保留独立Windows输入进程、过时移动合并与可靠按钮抬起。
- 诊断增加原生输入执行后的往返回执、估算的采集到呈现中位/P95和本机接收到呈现时间；缺失或过期数据留空。

## 安装和升级

Windows下载 `NearLink-0.1.7-win-x64.exe`；M系列Mac下载 `mac-arm64.dmg`，Intel Mac下载 `mac-x64.dmg`。

**Windows旧版若报“安装辅助进程未就绪便退出”，需先从托盘完全退出，再手动运行0.1.7安装包覆盖原位置一次。** 下载新包不会替换正在执行的旧更新器。可跳过中间版本，无需卸载或删除配对。之后的更新使用新启动器。

Mac也请更新至0.1.7，以使用新的按键映射。可在设置中更新，或完全退出后将DMG中的NearLink拖入“应用程序”覆盖。旧版若持续报ENOTEMPTY，可通过DMG覆盖升级，保留主数据目录。

后台检查不会自动中断远控；确认安装会结束当前会话。更新清单由固定发布密钥签名，下载后校验长度和SHA-256。

## 使用

两台电脑需开机并登录，处于互通的同一局域网。首次配对需双方核对完整指纹。Mac被控时授予屏幕录制、辅助功能及相应音频权限；发现失败时可填写对端设置页的IPv4:端口。

点击预览进入独立全屏窗口，顶部悬浮工具栏提供显示器、文件、画质、声音和诊断。退出全屏后可移动、缩放。最小化或×隐藏到后台，通过托盘/菜单栏恢复；“断开”结束会话，“完全退出”结束程序。

文件使用独立双栏窗口，支持文件夹选择、常用位置、多选、递归传输和完整性校验。文字/图片剪贴板及被控端系统声音默认启用，不采集麦克风。

Mac控制Windows时，Command+R对应Win+R，Option+Tab对应Alt+Tab，Control+C/V对应Ctrl+C/V；Command+V保留为Win+V。Windows控制Mac时，Windows键对应Command，Alt对应Option，Ctrl保持Control。

按源屏原生分辨率采集，最高3840×2160，低分辨率源不放大。画质菜单分别设置分辨率与目标帧率，支持自动流畅、原生清晰和原始像素显示。120fps尚未开放。

## 验证和限制

56项单元/回环网络测试和8项隐藏Electron回归通过，覆盖配对、输入队列、键盘、主线程阻塞、媒体后台恢复、故障重连、预览采集及更新。

[Windows隔离安装验证](https://github.com/tr1ee/NearLink/actions/runs/44714763522)已通过：真实PowerShell 5.1、最终包中的GUI启动器与NSIS安装器完成覆盖、版本校验、正常重启就绪及缓存删除；验证了启动器能在Node父进程退出后继续工作，Windows原生输入模块也实际加载成功。旧磁盘版本使用隔离夹具，未在用户0.1.5的界面中自动升级；Windows Server运行器不能替代用户Windows11、UAC和安全软件策略。

Mac Apple Silicon/Intel包均验证内置版本、代码一致性和嵌套签名；Mac为ad-hoc测试签名，尚未Apple公证。Windows未配置发布者签名。

本地媒体回归使用合成1080p画面与模拟输入；不能代表真实桌面采集、Wi-Fi、显卡和显示器。正常动态30fps、4K60、完整端到端响应及8小时稳定性仍需实机验收，不宣称已经达标。系统保留快捷键、高权限窗口和安全桌面受操作系统限制。

尚不提供手机端、跨互联网、登录前控制、系统服务或远程解锁。
