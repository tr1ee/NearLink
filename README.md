# 近控 NearLink

Windows 11 与 macOS 14.2+ 的局域网远程桌面测试版。本仓库发布安装包、更新清单和使用说明；应用源码暂未公开。

[下载 0.1.8 测试版](https://github.com/tr1ee/NearLink/releases/tag/v0.1.8)

## 0.1.8 更新

- 接收端使用原生即时播放策略，针对低网络RTT下仍积攒大量视频缓冲的画面滞后。网络抖动时可能增加迟到帧丢弃，不保证物理显示延迟为零。
- 仅变更码率时不再重复配置屏幕采集；编码过载时直接减轻分辨率负担，网络拥塞仍先降码率。
- 诊断增加实际视频编码格式、UDP/TCP媒体路径、缓冲目标和最低缓冲。导出记录包含启动播放策略与Chromium版本。
- 保留0.1.7的Windows独立输入进程、更新启动器、物理键盘映射和预览采集优化。

## 安装和升级

两端0.1.7可在“设置 → 软件更新”检查、下载并安装0.1.8。安装会结束当前会话，完成后重新打开应用，保留原有配对和设置。

Mac控制Windows时，本轮主要修复在Mac的视频接收端，请确认Mac已更新且新版进程已经重新启动。建议两端都更新，然后用相同显示器和画质对比“视频缓冲”“采集到呈现 · 中位/P95”和动态呈现fps。

手动安装：Windows下载 `NearLink-0.1.8-win-x64.exe`；M系列Mac下载 `mac-arm64.dmg`，Intel Mac下载 `mac-x64.dmg`。Mac完全退出后将DMG中的应用覆盖到原位置；Windows运行EXE覆盖原位置。无需卸载或删除配对。

早期Windows版本若更新辅助进程无法启动，可完全退出后手动覆盖一次。软件内更新清单使用原有发布密钥签名，安装包下载后校验长度和SHA-256。

## 使用

两台电脑需开机并登录，处于互通的同一局域网。首次配对需双方核对完整指纹。Mac被控时授予屏幕录制、辅助功能及相应音频权限；发现失败时可填写对端设置页的IPv4:端口。

点击预览进入独立全屏窗口，顶部悬浮工具栏提供显示器、文件、画质、声音和诊断。退出全屏后可移动、缩放。最小化或×隐藏到后台，通过托盘/菜单栏恢复；“断开”结束会话，“完全退出”结束程序。

文件使用独立双栏窗口，支持文件夹选择、常用位置、多选、递归传输和完整性校验。文字/图片剪贴板及被控端系统声音默认启用，不采集麦克风。

Mac控制Windows时，Command+R对应Win+R，Option+Tab对应Alt+Tab，Control+C/V对应Ctrl+C/V；Command+V保留为Win+V。Windows控制Mac时，Windows键对应Command，Alt对应Option，Ctrl保持Control。

按源屏原生分辨率采集，最高3840×2160，低分辨率源不放大。画质菜单分别设置分辨率与目标帧率，支持自动流畅、原生清晰和原始像素显示。120fps尚未开放。

## 验证和限制

58项单元/回环网络测试和4项隐藏Electron回归通过，覆盖真实WebRTC输入与视频、独立输入进程、预览复用、后台窗口和媒体进程恢复。受控合成测试中，主动请求160ms缓冲时，旧策略实际缓冲约139ms，新策略低于1ms；不代表用户真实Windows/Mac、Wi-Fi和物理显示器的测量结果。

[本次Windows安装验证](https://github.com/tr1ee/NearLink/actions/runs/44855112587)已通过：最终候选包实际完成PowerShell 5.1、GUI启动器和NSIS覆盖、0.1.8版本校验、新应用启动确认及安装缓存清理，Windows原生输入模块成功加载。旧磁盘版本使用隔离夹具；Windows Server运行器不能替代用户Windows11、UAC和安全软件策略。

三个架构安装包均核对内置版本、发布公钥与播放策略；Mac Apple Silicon安装包实际启动及签名校验通过。Mac为ad-hoc测试签名，尚未Apple公证；Windows未配置发布者签名。

正常动态30fps、4K60、完整端到端响应及8小时稳定性仍需真机验收。系统保留快捷键、高权限窗口和安全桌面受操作系统限制。尚不提供手机端、跨互联网、登录前控制、系统服务或远程解锁。
